# Solo-Flow

个人开发的公用工作流。一张 Issue 确定范围和验收方式，一个 PR 汇集候选、验证证据及 Human 验收。合并由 Human 对具体候选明确授权。

| 路径 | 用途 |
|---|---|
| [WORKFLOW.md](WORKFLOW.md) | 三问、实施与验证、停机、验收和收尾 |
| [MODEL_ROUTING.md](MODEL_ROUTING.md) | 可选的执行模型和推理档位建议 |
| [大脑指令](instructions/chatgpt-brain-v2.4.md) | 贴入项目会话，填写开头的仓库信息 |
| [Codex 指令](instructions/codex-AGENTS-v2.4.md) | 复制到项目根 `AGENTS.md`，保留项目补充 |
| [Issue 和 PR 模板](templates/.github/) | 复制到项目仓库的 `.github/` |
| [项目骨架](project-skeleton/) | 项目状态和节点档案模板 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 本仓结构和正式文档检查入口 |

项目特有的阶段状态、节点档案和架构说明放在对应项目仓库。
