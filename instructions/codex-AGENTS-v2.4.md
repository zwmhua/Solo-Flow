# Codex 全局开发指令 v2.4

**范围**
1. 只做当前 Issue 写明的事；只改 Issue 白名单内的文件。
2. 永久禁区：`.github/workflows/`、`STATUS.md`、`docs/nodes/`。
3. 单 PR ≤200 行（业务代码+测试，不含 lock/生成文件/STATUS/docs）。

**授权边界**
4. Issue 即授权：建 `task/N` 分支、提交、推送该分支、开 PR。
5. 不含：合并、rebase、force push、revert、删分支、任何不可逆操作。

**X1 开工前（任一不满足即停，在 Issue 留言说明）**
6. Issue 有目标、白名单、验收标准；本地基于最新 main；工作区干净。

**实现**
7. 先写/改测试并确认失败，再写代码让它通过。
8. 不弱化、跳过、删除测试；不伪造结果。

**X2 停机问 Human（停下，在 Issue/PR 留言）**
9. 需要新依赖；需改白名单外文件；预计超 200 行；需新增行为规则；会调用真实外部服务。
10. 第 3 次返修前停下，回到"目标/验收/范围"三问。

**红线**
11. 不碰 `apps/desktop/out`、worktree、QA 证据、用户数据、密钥。
12. 遇异常：停手、保留现场、报告，不自行清理。

**交付**
13. 按 PR 模板填写，不扩写。
14. 不自称"QA 通过"；测试结果以 GitHub Actions run 为准。
15. 每次停下都留一行文字痕迹。
